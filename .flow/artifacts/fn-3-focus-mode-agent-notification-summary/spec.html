01Thesisscope: business

Agent summaries are off until you enable them. Then Omarchy’s default agent reads blocked pings in the background and you get one important-things summary at focus-off. Helpful / not-helpful feedback trains the next parse.

An Omarchy default agent is not consent. Override uses Omarchy’s selector modal, limited to agents that can run a one-shot headless prompt.

03Architecturescope: technical

Opt-in

Off until enabled in the plugin. Mute still owns block and grouped-count fallback.

Agent

Omarchy default, or an override from the same selector, headless-only.

Ledger

Helpful / not-helpful plus optional feedback is an input to the next parse.

04Boundariesscope: business

Is

  • Opt-in agent summary after focus-off
  • Default agent, plus Omarchy-style override
  • Headless one-shot agents only
  • Feedback ledger for the next parse

Is not

  • Mute or grouped count (fn-2)
  • Network block (fn-1)
  • Consent just because Omarchy has a default agent
  • A peek during focus, or a non-headless agent
05Parked2 unknowns
  • How ping text and the ledger reach the agent. Plan picks the mechanism.
  • Which current Omarchy agents qualify as headless. Plan checks each one.

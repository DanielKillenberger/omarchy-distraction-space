01Thesisscope: business

Agent summaries are off until you enable them. This plugin captures blocked-ping text itself, Omarchy’s default agent reads it in the background, and you get one important-things summary at focus-off. The mute grouped count stays the catch-up when this path is off or fails.

An Omarchy default agent is not consent (R13). The plugin reads omarchy default agent, picks with omarchy-menu-select, and runs a gated print/run/exec argv table. It does not call omarchy agent prompt. It does not read a mute raw-ping queue.

04Architecturescope: technical

Capture

Plugin service writes JSONL {app,title,body,at}. Does not dismiss. Does not increment mute counts.

Identity

omarchy default agent, or a plugin-local summary_agent from omarchy-menu-select.

One-shot

Offered print/run/exec argv. Tool-free flags. Empty cwd. No TUI. No auto-approve.

summaries off → grouped count no usable agent / empty text → grouped count parse or display fail → grouped count success → one summary + silent clear

06Boundariesscope: business

Is

  • Opt-in agent summary after focus-off
  • Owned ping-text capture
  • Default agent, plus offered-table override
  • Feedback ledger for the next parse

Is not

  • Mute or grouped count (fn-2)
  • A mute raw-ping queue
  • omarchy agent prompt, ori, pi, copilot
  • History, allow-list, or peek while focused
07DecisionsMAJOR_RETHINK replan
D3 · ping text

Mute stores counts and discards banners. This spec writes JSONL.

Plugin service owns {app,title,body,at}. Mute count file is not a text queue.

Rejected: depending on an fn-2 raw-ping queue.

D4 · focus-off XOR

Grouped count stays the catch-up when summaries are off or the one-shot fails.

Lift, then one summary with silent clear, or show_grouped_notice().

Rejected: waiting after disable_focus() and suppressing a notice that already fired.

D5 · offered table

“well any of them that allow headless invocation like claude -p or similar”

claude, codex, grok, omp, agy with exact tool-free argv. Default lookup and R13 kept.

Rejected: ori, pi, copilot, and unverified opencode/crush rows. Rejected: omarchy agent prompt.

08Early prooftask .1

Task .1 proves the invoke path. omarchy default agent resolves, omarchy-menu-select can write an override, and one offered-table argv returns stdout or a clear failure without opening a TUI and without tools. If it fails, re-evaluate the offered table before capture or focus-off wiring.

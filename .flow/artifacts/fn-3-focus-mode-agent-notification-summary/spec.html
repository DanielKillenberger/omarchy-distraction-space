01Thesisscope: business

Agent summaries are off until you enable them. Then Omarchy’s default agent reads blocked pings in the background and you get one important-things summary at focus-off. Helpful / not-helpful feedback trains the next parse.

An Omarchy default agent is not consent (R13). The plugin reads omarchy default agent, picks with omarchy-menu-select, and runs a closed print/run/exec argv table. It does not call omarchy agent prompt.

04Architecturescope: technical

Consent

agent_summaries in focus.json defaults false. Plugin enable is required.

Identity

omarchy default agent, or a plugin-local summary_agent from omarchy-menu-select.

One-shot

Closed print/run/exec argv. Stdout is the summary. No TUI. No auto-approve.

summaries off → grouped count no default / empty buffer → grouped count parse or display fail → grouped count success → one summary + ledger
05Edge casesblast radius

Focus session

Cancel in-flight parse on focus-on. One wait-then-kill at focus-off. Reason cancel stays focused.

Invoke

Missing binary, unknown id, empty stdout (including agy non-TTY), non-zero exit → R1 then R6.

State

Flock result and ledger files. No peek command while focus is on. CLI focus-off still runs the chain.

06Boundariesscope: business

Is

  • Opt-in agent summary after focus-off
  • Default agent, plus Omarchy-style override
  • Headless one-shot agents only
  • Feedback ledger for the next parse

Is not

  • Mute or grouped count (fn-2)
  • Network block (fn-1)
  • Consent just because Omarchy has a default agent
  • omarchy agent prompt, peek, history, or allow-list

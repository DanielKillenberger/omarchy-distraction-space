One session: purpose and minutes at start, then a configurable close that hosts the shipped missed-summary. The parser is already merged. This spec hosts it. It does not rebuild it.

Timer expiry skips the 50-character leave reason. Leaving by hand still requires it. Hiding purpose or self-eval never hides a shipped summary.
01

Acceptance

scope: both · 4 R-IDs
IDCriterionSource
R1Omarchy-styled start popup. Required purpose (any non-empty). Minutes start at 25, accept 1 to 240, refuse the rest. Confirm starts focus. Dismiss or invalid input leaves focus off.user
R2Timer turns focus off without the 50-character reason. Hand-off still requires it. Purpose goes to the disable log. The bar stays an eye.user
R3After focus is off, one window can show purpose, shipped missed-summary, optional self-eval, and helpful / not-helpful. Hosts fn-3. Drops the extra summary notify and helpful dialog.user
R4Fully configurable in existing focus settings, including an agent-editable config. Defaults on for window, purpose, eval; summary if enabled. Hiding purpose or eval never hides a shipped summary.user
02

Boundaries

scope: business
Is
  • Start popup with purpose and minutes
  • Timer auto-disable
  • Configurable closing window that hosts the shipped summary
Is not
  • A second parser, capture path, or ledger
  • Changing the written reason to leave by hand
  • Session history or a purpose archive
  • Contingency UI for a dialog that did not open
03

Decision

scope: both
Motivation
One session that starts with purpose and time and closes with one window.

“we should have a ui popup when entering focus mode that matches the omarchy style to input the purpose of the focus session and the time after which it will be automatically disabled”

01Thesisscope: business

The plugin owns a maintainable membership list with a plugin UI. Listed apps open only on the distraction workspace. Website versions are network-blocked on every other workspace.

Load-bearing carve: one list, two enforcements. App windows land only on the distraction space. Corresponding sites do not load anywhere else. Focus-mode extra destinations (YouTube, Netflix) stay the sibling spec.

03Architecturescope: technical

One list + UI

Plugin-owned membership. Each entry covers the app and its website version. A plugin UI edits the list. A file may back that UI.

Exclusive land

A listed app window opens only on the named distraction workspace. It does not open on any other workspace.

Workspace-gated sites

While the active workspace is not the distraction space, corresponding sites are network-blocked. A shared-browser tab stays put.

05Boundariesscope: business

Is

  • A plugin-owned list of apps that auto-open on the distraction workspace
  • Exclusive app-window placement plus a workspace-gated site block
  • A plugin UI to maintain the list, with shipped defaults

Is not

  • Focus-mode extra destinations such as YouTube and Netflix (sibling spec)
  • Notification blocking (sibling spec)
  • A file-only maintenance path with no plugin UI
06Decisionsflat context
D1 · native list

"that should be a native configuration list in the plugin"

Chosen path: the plugin owns membership. The user does not copy window rules to maintain it.

Rejected: leaving auto-assign as copied window-manager snippets.

D2 · exclusive + websites

"in any other workspace they don't open at all (even the website versions)"

Chosen path: exclusive placement stays in this spec. Website versions are the same membership.

Rejected: a separate spec for exclusivity, or shipping the list without website versions.

D3 · workspace-gated sites

"block corresponding sites on the network level as we are on any other workspace than distraction space"

Chosen path: network-block this list's sites while the active workspace is not the distraction space. The browser window stays put.

Rejected: moving a shared browser, or treating website matching as a later spec.

D4 · plugin UI

"i wouldn't decline extra ui by default"

Chosen path: a plugin UI is required to edit the list. A file may back that UI.

Rejected: importing the fn-2 no-extra-UI decline, or shipping file-only.

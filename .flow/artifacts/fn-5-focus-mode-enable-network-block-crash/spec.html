Focus-mode enable network-block crash

Statusopen / ready

Activationmanual work, no-plan

Turning focus on crashed with a type error before the network block could retry privilege. Focus stayed off. This spec is only that crash, not the already-done network-block feature.

New spec beside fn-1. Privilege-command failure output must decode as text so permission denied can retry pkexec/sudo instead of aborting as a type error.
